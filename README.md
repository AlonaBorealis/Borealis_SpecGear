# [Borealis] SpecGear — комплект по спеку

Аддон для WoW 3.3.5a (WotLK), русский клиент. Других аддонов не требует.

## Что умеет

Когда ты меняешь набор талантов, аддон сам надевает комплект экипировки, выбранный для нового спека, и пишет об этом в чат. Если для спека выбрано «Ничего не делать», при смене спека ничего не происходит.

Спек в бою сменить нельзя, поэтому переодевание всегда идёт вне боя. Сразу после смены спека игра на мгновение блокирует вещи, поэтому аддон несколько раз повторяет попытку и, если не получилось, пишет об этом.

## Настройка

1. Включи менеджер экипировки: Интерфейс → галочка «Использовать менеджер экипировки».
2. В окне персонажа (C) сохрани комплекты в менеджере экипировки, например «Хил» и «ДД».
3. Введи `/sg` (или Интерфейс → Модификации → «SpecGear») и выбери комплект для спека 1 и спека 2.

Настройки свои у каждого персонажа.

## Установка

1. Закрой игру.
2. Распакуй архив так, чтобы папка `borealis_SpecGear` оказалась в `Interface\AddOns`.
3. Зайди в игру и проверь, что аддон включён в списке модификаций.
